## Task Structure

Each task follows the standard structure:
- docs/ - Documentation files (agent_system_prompt.md, task.md, user_system_prompt.md)
- evaluation/ - Evaluation scripts (main.py)
- groundtruth_workspace/ - Ground truth data (readme.txt)
- initial_workspace/ - Initial workspace data (readme.txt)
- preprocess/ - Preprocessing scripts (main.py)
